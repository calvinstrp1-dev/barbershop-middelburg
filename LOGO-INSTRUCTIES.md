# Logo Uploaden - Instructies

## Belangrijk!

Het geüploade logo moet handmatig worden toegevoegd aan het project.

### Stappen:

1. **Bewaar uw logo bestand** als `logo.png`

2. **Plaats het bestand** in de `public` folder van het project:
   ```
   barbershop-website/public/logo.png
   ```

3. **Het logo wordt automatisch gebruikt** op de volgende plekken:
   - Navigatie (boven aan de pagina)
   - Hero sectie (grote logo in het midden)
   - Footer (onderaan de pagina)

### Alternatief:

Als u via de terminal werkt, gebruik dan:

```bash
# Kopieer uw logo naar de public folder
cp /pad/naar/uw/logo.png barbershop-website/public/logo.png
```

### Ondersteunde formaten:

- PNG (aanbevolen)
- JPG/JPEG
- SVG
- WebP

Het logo wordt automatisch geschaald naar de juiste grootte op elke plek!
